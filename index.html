Hamkar ہمراہ کار v2 — AI Teammates

Named AI Bots with roles, memory, Skills, Routines, Automations, a Vault and an approval queue. Free, no account, no card. AI: checking…

Honest limits: AI replies need the owner's Gemini key (free quota). Without it, Bots, Skills, Routines, Automations, memory, Vault, workspaces and export/import still work. Routines and Automations run while this page is open — there is no server cron. No cloud computer per Bot — each Bot's workspace is local files in your browser. No real web browsing, email sending, meeting joins or live connectors. Webhook triggers need a server endpoint (not in this build) — use Run now or a time trigger. A Bot only proposes actions; nothing is ever sent, deleted or published without your approval. Vault values are never shown in chat, never logged, never pasted into messages.
